## 📌 Project Overview

The Cybersecurity Awareness Chatbot is an interactive desktop application built using **C# WPF (.NET)**.

It is designed to educate users about cybersecurity in a **simple, engaging, and conversational way**.

The chatbot simulates a real assistant that:
- Responds to cybersecurity questions
- Detects user emotions
- Remembers user preferences
- Provides dynamic and varied answers

---

## 🎯 Purpose of the Project

The goal of this project is to:
- Raise awareness about cybersecurity risks
- Teach safe online behaviour
- Demonstrate OOP, collections, and delegates in C#
- Build an interactive GUI-based chatbot system

---

## 🖥️ Technologies Used

- C#

## ✨ Features

### 🧠 1. Keyword Recognition
The chatbot detects cybersecurity-related keywords such as:
- Passwords
- Phishing
- Malware
- Scams
- Privacy
- VPN
- Encryption
- Social engineering

It then provides relevant advice automatically.

---

### 😊 2. Sentiment Detection
The chatbot detects user emotions such as:
- Worried
- Frustrated
- Curious
- Happy
- Confused
- Angry
- Excited

It adjusts responses to match the user’s emotional state.

---

### 💾 3. Memory System
The chatbot remembers:
- User name
- Favourite cybersecurity topic

It uses this information to personalise responses.

Example:
> "As someone interested in privacy, here are some tips..."

---

### 🔁 4. Conversation Flow
The chatbot understands follow-up inputs such as:
- “tell me more”
- “another tip”
- “explain more”
- “continue”

This allows natural conversation flow without restarting context.

---

### 🎲 5. Random Responses
Multiple responses are stored for topics and selected dynamically to keep conversations varied and engaging.

---

### 🎤 6. Voice Greeting
A WAV audio file plays when the application starts to greet the user.

---

### 🖥️ 7. Graphical User Interface (GUI)
Built using WPF with:
- Modern dark theme design
- Chat bubble interface
- Scrollable chat window
- Logo display
- Send button + keyboard input support

---

### 🔗 8. Delegate Implementation
A C# delegate is used to log chat messages for system tracking and debugging purposes.
