# Changelog

All notable changes to the Panashe Cybersecurity Awareness Chatbot.

---

## [v1.1] - 2026-05-31

### Added
- Full WPF GUI interface with chat bubbles
- Typing animation effect for bot responses
- Color-coded message bubbles based on sentiment detection
- Voice greeting on application startup (`greetings (1).wav`)
- Logo image integration (`nash-logo.jpeg`)
- ASCII art logo display
- YouTube video presentation included in project

### Changed
- Improved keyword response system with 20+ cybersecurity topics
- Enhanced sentiment detection with 12 emotion types
- Better user personalisation with memory storage

### Fixed
- Cross-platform audio playback (Windows, Mac, Linux)
- Delegate pattern implementation for message logging

---

## [v1.0] - 2026-05-30

### Added
- Core ChatBot engine with keyword response system
- SentimentDetector for emotion analysis
- MemoryStore for personalised user experience
- KeywordResponder with cybersecurity topics:
  - Password safety
  - Phishing awareness
  - Malware protection
  - Privacy and data protection
  - VPN and encryption
  - 2FA and MFA
  - Social engineering
  - And 15+ more topics
- ChatLogger with delegate pattern
- Audio playback support for voice greeting
- User class for name storage
- Basic console UI helper methods

### Technical
- Built with C# and .NET Framework
- WPF architecture
- Sentiment analysis with keyword scoring
- Rotating response system for varied answers
